# جلسة إصلاح مشكلة انقطاع السيرفر (ECONNREFUSED 8000)

**تاريخ الجلسة:** 13 مايو 2026
**وقت البداية:** 12:11 مساءً
**وقت النهاية:** 12:21 مساءً

## المشكلة
واجه المستخدم مشكلة في الداشبورد (Vite على بورت `5173`) تتمثل في ظهور أخطاء بروكسي لعدم قدرته على الوصول إلى السيرفر الخلفي (`http proxy error: connect ECONNREFUSED 127.0.0.1:8000`).

## التحليل والتشخيص
1. **تأكيد حالة السيرفر:** عند تشغيل أداة `Start_Robot.bat`، كان النظام يطبع `ROBOT SERVER READY` لكن السيرفر على بورت 8000 يختفي بعدها فوراً ويفشل بصمت.
2. **عزل المشكلة:** تم إنشاء سكريبت اختباري `test_server.py` وتشغيله للتحقق من أن تطبيق FastAPI/Uvicorn يعمل بشكل سليم وبورت 8000 غير محجوز. ثبت أن الويب سيرفر نفسه يعمل بنجاح ويرد بـ 200 OK.
3. **التشخيص الجذري:** من خلال مراجعة ملف التشغيل الأساسي للذكاء الاصطناعي `d:\robot new version\brain\runtime.py` (وتحديداً الدالة `run()`)، تم اكتشاف أن النظام كان يستخدم `asyncio.gather` لتشغيل 7 مهام متوازية (منها الويب سيرفر، الكاميرا، الميكروفون والصوت، ومستشعرات الحرارة).
4. **سبب الانهيار:** دالة `asyncio.gather` مصممة بحيث إذا فشلت **مهمة واحدة**، تقوم بإلغاء كل المهام الأخرى وإغلاق السيرفر. وفي هذه الحالة، كان يتوقف مفتاح الـ API الخاص بـ Gemini Live للصوت (بسبب اكتشاف تسريبه `Your API key was reported as leaked`)، مما يؤدي لفشل مهمة الـ `voice_loop`، وهو ما تسبب في توقف النظام بأكمله بما فيه واجهة الداشبورد.

## التعديلات التي تمت
- **الملف المعدل:** `d:\robot new version\brain\runtime.py` (من السطر 1135 فصاعداً).
- **التعديل:** تمت إضافة نظام حماية "Resilient Task Wrapper" (`_resilient`). 
- **آلية العمل الجديدة:** تم تغليف كل المهام الفرعية غير الحرجة (الكاميرا، الصوت، الحرارة، حالة الاتصال) بداخل هذا الغلاف. إذا تعطلت الكاميرا أو فشل الميكروفون (كما حدث بسبب مفتاح الـ API)، يقوم النظام الآن بتسجيل الخطأ في السجلات (Logs) ويكمل عمله بشكل طبيعي بدلاً من إغلاق السيرفر بالكامل.

## النتيجة
- السيرفر الأساسي (Web Server و Command Processor) أصبح مستقلاً ومنيعاً ضد أخطاء الحساسات الفرعية.
- الـ Backend الآن يعمل باستقرار تام على بورت `8000`.
- تم حل مشاكل الـ Proxy Error، وأصبح الداشبورد متصلاً بالسيرفر بشكل صحيح ومستقر.
